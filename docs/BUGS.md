# Bug Tracker

## Status saat ini

Saat ini tidak ada bug terbuka yang terdokumentasi atau dilaporkan pada repository AURA.

Pencarian pada source juga tidak menemukan penanda `TODO`, `FIXME`, `BUG`, atau `HACK` yang menunjuk ke issue terbuka.

## Catatan ruang lingkup

Beberapa kemampuan masih berupa fondasi atau placeholder, misalnya cek/pembatalan reservasi dan `DatabaseTool`. Hal tersebut dicatat sebagai pekerjaan pengembangan di [ROADMAP.md](ROADMAP.md), bukan sebagai bug terbuka.

## Format pelaporan berikutnya

Jika bug ditemukan, tambahkan entri dengan format berikut:

```markdown
## [OPEN] Judul singkat

- Dampak:
- Langkah reproduksi:
- Hasil yang diharapkan:
- Hasil aktual:
- Status:
```
